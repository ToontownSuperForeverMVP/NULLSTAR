## Additional verified hardening

Repeated reservations for the same strike previously overwrote its remaining count. They now fail, including after jobs are enqueued; accounting uses long arithmetic to reject overflow-sized requests. Catalog collections no longer expose mutable removal. Failed terrain visitors charge already-scanned candidates before continuing other work. The JDK 25 guard runs in settings before Loom applies; an actual Java 21 invocation fails with the intended actionable message.

The original candidate cursor, geometry caps, loaded-chunk-only access, container/unbreakable/claim/vanilla protection and mutation flags remain intact. Singularity retains bounded living-entity attraction; Glassfall retains five reserved, staggered impacts; Helios retains its full phase/crater loop. Cancellation never undoes already changed blocks. Camera Mixin injection and v1 payload schemas are unchanged.
